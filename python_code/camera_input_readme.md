# 1단계 : 카메라 영상 입력 확인 (Camera Input)

## 목적

Jetson Orin Nano에서 USB 웹캠 영상을 정상적으로 수신하고 **실시간으로 출력**할 수 있는 환경을 구축합니다.

---

## 개요

`camera_input.py`는 **OpenCV + GStreamer** 백엔드를 활용하여 USB 카메라로부터 영상을 입력받아 실시간으로 화면에 출력하는 스크립트입니다.  
영상 출력 시 **FPS(초당 프레임 수)**를 실시간으로 측정하여 화면에 표시합니다.

---

## 지원 카메라 타입

| 타입 | 설명 | GStreamer 소스 |
|------|------|----------------|
| **USB 카메라** | 일반 USB 웹캠 | `v4l2src` |

---

## 환경 요구사항

### 하드웨어
- NVIDIA Jetson Orin Nano
- USB 웹캠

### 소프트웨어
- **JetPack SDK** (권장: 5.x 이상)
- **Python 3.8+**
- **OpenCV** (GStreamer 지원 빌드)
  - Jetson의 JetPack에 기본 포함되어 있음

### OpenCV GStreamer 지원 확인

```bash
python3 -c "import cv2; print(cv2.getBuildInformation())" | grep GStreamer
```

출력에 `GStreamer: YES`가 표시되어야 합니다.

---

## 기본 설정값

| 항목 | USB 카메라 |
|------|-----------|
| **해상도** | 640 x 480 |
| **FPS** | 30 |
| **장치** | `/dev/video0` |

> **참고:** 해상도와 FPS는 코드 내 `get_usb_pipeline()` 함수의 파라미터를 수정하여 변경할 수 있습니다.

---

## 실행 방법

Jetson에 USB 웹캠을 연결하고, 아래 명령어를 실행하면 별도 설정 없이 바로 카메라 화면이 출력됩니다.

```bash
python3 camera_input.py
```

---

## 출력 화면

- **실시간 영상**: OpenCV 윈도우(`Jetson Camera Viewer`)에 카메라 영상 표시
- **FPS 표시**: 화면 좌측 상단에 초록색 텍스트로 현재 FPS 출력 (0.5초 간격 갱신)

### 종료 방법
영상 창을 선택한 상태에서 **`q` 키**를 누르면 종료됩니다.

---

## 확인 사항 체크리스트

| 확인 항목 | 확인 방법 |
|----------|----------|
| **영상이 끊기지 않는가** | 영상 창에서 움직임이 부드럽게 표시되는지 육안 확인 |
| **FPS는 몇인가** | 화면 좌측 상단 `FPS: xx.x` 수치 확인 (목표: 30 FPS) |
| **지연시간은 어느 정도인가** | 카메라 앞에서 손을 흔들어 화면에 표시되기 파지의 체감 지연 확인 |

## 트러블슈팅

| 증상 | 원인 및 해결 |
|------|-------------|
| `카메라를 열 수 없습니다` | 카메라 연결 확인. `ls /dev/video*`로 장치 존재 여부 확인 |
| `프레임을 읽어올 수 없습니다` | 해상도/FPS가 카메라 지원 범위 밖일 수 있음. 값 조정 필요 |
| FPS가 매우 낮음 | 해상도를 낮추거나 GStreamer 파이프라인 최적화 |
