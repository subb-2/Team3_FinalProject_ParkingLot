# 2.5단계 : 고유 ID 부여 및 빈자리 매칭

## 목적

ZYBO(추론 보드)가 UART로 넘겨준 차량 번호 정보를 Jetson에서 수신하여 **고유 ID를 부여**하고, **가장 가까운 빈자리를 매칭**합니다.

---

## 개요

`id_manage.py`는 ZYBO로부터 **UART 통신**을 통해 8비트 차량 데이터를 수신하고, 하위 4비트에서 차량 번호를 추출한 뒤, 순차적으로 **Track ID를 할당**하며 현재 비어 있는 주차 자리 중 **가장 가까운 자리(번호가 작은 자리)**를 자동 배정하는 스크립트입니다.

UART 장치 없이도 동작을 확인할 수 있는 **데모 모드**가 포함되어 있습니다.

---

## 데이터 형식

### UART 입력 (8비트)

```
비트:  [7] [6] [5] [4] [3] [2] [1] [0]
       ─────────────── ───────────────
        상위 4비트        하위 4비트
        (예약/미사용)    (차량 번호)
```

| 필드 | 비트 범위 | 설명 |
|------|----------|------|
| 상위 비트 | [7:4] | 예약 (현재 미사용) |
| **차량 번호** | **[3:0]** | **차량 고유 번호 (1~15)** |

### 입력 예시

| 원본 (8비트) | 16진수 | 추출된 차량 번호 |
|-------------|--------|---------------|
| `0000_0001` | `0x01` | 1 |
| `0000_1010` | `0x0A` | 10 |
| `0001_0011` | `0x13` | 3 (하위 4비트만) |

### 출력 형식

```
{car_num, id}
```

| 필드 | 설명 | 예시 |
|------|------|------|
| `car_num` | 8비트 원본 (이진수 문자열) | `00001234` |
| `id` | 할당된 고유 Track ID | `1`, `2`, `3`, ... |
| `spot_id` | 배정된 주차 자리 번호 | `1`, `2`, `3`, ... |

## UART 연결 설정

### Jetson Orin Nano UART 핀

| 핀 | 기능 | 연결 대상 (ZYBO) |
|----|------|----------------|
| **Pin 8** | UART TX | ZYBO RX |
| **Pin 10** | UART RX | ZYBO TX |
| **Pin 6** | GND | ZYBO GND |

### 기본 UART 설정

| 항목 | 값 |
|------|---|
| **포트** | `/dev/ttyTHS1` |
| **보드레이트** | 115200 bps |
| **데이터 비트** | 8 |
| **패리티** | None |
| **스톱 비트** | 1 |

> **참고:** Jetson의 UART 포트가 다른 경우 코드 상단의 `UART_PORT` 상수를 수정하세요.

## 데모 모드 사용법

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `[숫자]` | 해당 8비트 값의 차량 입차 | `3` → 차량번호 3 입차 |
| `r [숫자]` | 해당 차량번호 출차 | `r 3` → 차량번호 3 출차 |
| `s` | 주차장 현황 보기 | - |
| `q` | 종료 | - |

### 데모 실행 예시

```
입력> 1
[UART] 수신 원본: 00000001 (0x01)
[UART] 추출 차량 번호: 1 (하위 4비트: 0001)

[결과] 차량 매칭 완료:
  car_num : 00000001
  id      : 1
  spot    : 1

========== 주차장 현황 ==========
  전체: 10  |  사용: 1  |  빈자리: 9
----------------------------------------
  자리  1: 🚗 차량 1 (ID: 1, 입차: 2026-07-26 10:40:00)
  자리  2: ⬜ 빈자리
  자리  3: ⬜ 빈자리
  ...
========================================

입력> r 1
[INFO] 차량 1 출차 완료. 자리 1 반납.
```

## 핵심 로직

### 빈자리 매칭 알고리즘

```
1. UART에서 8비트 데이터 수신
2. 하위 4비트 추출 → 차량 번호
3. 이미 등록된 차량인지 확인
   ├─ 등록됨 → 기존 정보 반환
   └─ 미등록 → 다음 단계로
4. 빈자리 목록 조회 (번호 오름차순)
5. 가장 작은 번호(가까운 자리) 배정
6. 고유 Track ID 부여 (순차 증가)
7. 결과 반환: {car_num, id, spot_id}
```

### 스레드 안전성

- `ParkingManager` 클래스 내부에 `threading.Lock`을 사용하여 동시 접근 시에도 데이터 무결성을 보장합니다.

## 확인 사항 체크리스트

| 확인 항목 | 확인 방법 |
|----------|----------|
| **UART 입력값이 잘 넘어오는지** | 터미널에 `[UART] 수신 원본: xxxxxxxx` 로그 확인 |
| **고유 ID가 할당되는지** | 매칭 결과의 `id` 값이 순차적으로 증가하는지 확인 |
| **빈자리 잘 매칭해주는지** | 가장 작은 번호의 빈자리부터 배정되는지 확인 |
| **정보 업데이트 잘하는지** | 입차/출차 후 `s` 명령으로 현황이 정확히 반영되는지 확인 |

## 트러블슈팅

| 증상 | 원인 및 해결 |
|------|-------------|
| `UART 포트를 열 수 없습니다` | 포트 경로 확인 (`ls /dev/ttyTHS*`), 권한 확인 (`sudo chmod 666 /dev/ttyTHS1`) |
| 데이터가 수신되지 않음 | TX/RX 크로스 연결 확인, 보드레이트 일치 확인, GND 연결 확인 |
| `ModuleNotFoundError: serial` | `pip install pyserial` 실행 (주의: `serial`이 아닌 `pyserial`) |
| 빈자리가 없다는 메시지 | `TOTAL_PARKING_SPOTS` 값을 늘리거나 기존 차량 출차 처리 |
