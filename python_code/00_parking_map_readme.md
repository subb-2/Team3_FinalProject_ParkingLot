# 00_parking_map 모듈 명세서 (README)

## 개요

주차장 전체를 **2D 그리드(15행 × 13열)** 격자판으로 관리하는 핵심 모듈입니다.
도로, 주차 구역, 벽(장애물), 입출구를 모두 하나의 격자판 위에서 관리하며,
BFS(너비 우선 탐색) 기반 최단경로 탐색 및 빈자리 추천 기능을 제공합니다.

## 셀 타입 상수

| 코드 | 상수명 | 의미 | 설명 |
|:---:|:---:|:---:|:---|
| `0` | `WALL` | 벽 | 이동 불가 영역 (건물, 경계선, 중앙 섬 내부) |
| `1` | `ROAD` | 도로 | 차량이 이동 가능한 통로 |
| `2` | `SPOT` | 주차 구역 | 주차 가능한 자리 (빈자리/주차중 구분) |
| `3` | `GATE` | 입출구 | 차량 진입/퇴장 지점 (하나의 통로로 공유) |

## 그리드 맵 구조 (15행 × 13열)

```
row  0  : 상단 외벽
row  1  : A구역 주차칸 (A-1 ~ A-4, 각 2칸 폭)
row  2  : A구역 앞 도로
row  3  : 입출구(GATE) + 도로
row  4  : 도로
row  5  : 중앙 섬 상단 도로
row  6  : C구역 주차칸 (C-1 ~ C-3, 각 2칸 폭)
row  7  : 중앙 섬 내부 벽
row  8  : D구역 주차칸 (D-1 ~ D-3, 각 2칸 폭)
row  9  : 중앙 섬 하단 도로
row 10  : 도로
row 11  : 도로
row 12  : B구역 앞 도로
row 13  : B구역 주차칸 (B-1 ~ B-4, 각 2칸 폭)
row 14  : 하단 외벽
```

## 주차 구역 좌표 매핑 (spot_map)

각 주차 구역은 2칸 폭으로 구성되며, 좌표는 `(row, col)` 형식입니다.

| 구역 ID | 좌표 1 | 좌표 2 |
|:---:|:---:|:---:|
| A-1 | (1, 1) | (1, 2) |
| A-2 | (1, 4) | (1, 5) |
| A-3 | (1, 7) | (1, 8) |
| A-4 | (1, 10) | (1, 11) |
| B-1 | (13, 1) | (13, 2) |
| B-2 | (13, 4) | (13, 5) |
| B-3 | (13, 7) | (13, 8) |
| B-4 | (13, 10) | (13, 11) |
| C-1 | (6, 4) | (6, 5) |
| C-2 | (6, 7) | (6, 8) |
| C-3 | (6, 10) | (6, 11) |
| D-1 | (8, 4) | (8, 5) |
| D-2 | (8, 7) | (8, 8) |
| D-3 | (8, 10) | (8, 11) |

## 입출구 좌표

- **GATE_POS**: `(3, 0)` — 좌측 중앙, 입구와 출구가 같은 위치

## 주요 함수

### `find_shortest_path(start, end)`
BFS를 사용하여 start에서 end까지의 최단경로 좌표 리스트를 반환합니다.

### `find_nearest_empty_spot(occupied_spots)`
입출구(GATE)에서 가장 가까운 빈 주차 구역 ID와 경로를 반환합니다.

### `print_map(occupied_spots)`
터미널에 현재 주차장 상태를 이모지로 시각화하여 출력합니다.
- 🅿️ : 빈자리
- 🚗 : 주차된 차량
- 🚪 : 입출구
- ██ : 벽
