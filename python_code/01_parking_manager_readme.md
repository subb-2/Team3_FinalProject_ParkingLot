# 01_parking_manager 모듈 명세서 (README)

## 개요

차량의 **입출차 처리**, **주차 시간 기록**, **요금 계산**, **차량 정보 조회** 등을 담당하는 주차 관리 모듈입니다.
`00_parking_map` 모듈의 맵 데이터와 연동하여 전체 주차장 시스템을 운영합니다.

## 요금 체계

`get_fee_config()` 함수에서 설정값을 관리합니다.

| 항목 | 기본값 | 설명 |
|:---|:---:|:---|
| `base_minutes` | 30분 | 기본 요금이 적용되는 시간 |
| `base_fee` | 1,000원 | 기본 요금 |
| `extra_per_minutes` | 10분 | 추가 요금 단위 시간 |
| `extra_fee` | 500원 | 추가 요금 단위 금액 |

### 요금 계산 예시

| 주차 시간 | 계산 | 요금 |
|:---:|:---|:---:|
| 20분 | 기본 요금 | 1,000원 |
| 30분 | 기본 요금 | 1,000원 |
| 40분 | 1,000 + (10분 초과 → 1단위 × 500) | 1,500원 |
| 60분 | 1,000 + (30분 초과 → 3단위 × 500) | 2,500원 |

## 데이터 구조

### parked_cars (주차 구역 기준)
```python
{
    "A-1": {"car_id": "1234", "entry_time": datetime(...)},
    "C-2": {"car_id": "5678", "entry_time": datetime(...)},
}
```

### car_to_spot (차량 번호 기준, 역방향 검색용)
```python
{
    "1234": "A-1",
    "5678": "C-2",
}
```

## 주요 함수

### `park_car(spot_id, car_id)`
지정된 주차 구역에 차량을 입차 처리합니다. 입차 시간은 현재 시각으로 자동 기록됩니다.

### `remove_car(car_id)`
차량 번호로 출차 처리를 하고, 주차 요금을 계산하여 반환합니다.

### `calculate_fee(duration_minutes)`
주차 시간(분 단위)을 기반으로 요금을 계산합니다.

### `get_occupied_spots()`
현재 주차 중인 구역 ID의 set을 반환합니다. `00_parking_map`의 `find_nearest_empty_spot()` 함수에 인자로 넘겨 빈자리 추천에 활용합니다.

### `get_car_info(car_id)` / `get_spot_info(spot_id)`
차량 번호 또는 구역 ID로 주차 정보를 조회합니다.

### `print_all_parked()`
현재 주차 중인 모든 차량 정보를 테이블 형태로 출력합니다.
